# Sung Choi × Concord 风格参考库

个人学习与风格研究用。含 `STYLE_REFERENCE.html` 风格页、参考图与 `STYLE_ANALYSIS.md`。

## 在线阅览

若已开启 GitHub Pages，打开仓库 Settings → Pages 给出的站点地址，或访问本仓库 Pages URL。

本地也可直接打开根目录的 `STYLE_REFERENCE.html`。

## 风格测试输出

四轮 Aiart Concord 风格迭代（prompt、说明与 contact-sheet 等）见 [`OUTPUTS.md`](OUTPUTS.md) 与根目录 `outputs/`。**仅供个人学习与风格研究**，请勿当作商用素材。
